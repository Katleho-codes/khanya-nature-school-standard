# Photograph brief

The demo seed points at the filenames below. They are deliberately not checked in, so the site uses its on-brand placeholders until real photographs are added here. Drop each file into this folder with the exact name shown. Do not rename files in the CMS unless you also replace the matching file.

## Rules for every image

- Format: JPEG, sRGB, quality 80 to 90.
- Maximum upload size: 8 MB. The CMS also accepts PNG and WebP for new uploads, but the seeded filenames are `.jpg`.
- Crop for the stated ratio. Keep the subject away from the outer 5% so responsive crops do not cut faces or hands.
- Minimum sizes below are the smallest acceptable files. Larger files are welcome, especially for full-width heroes.
- No text, logos, borders or filters baked into the image.
- Children must be shown with the school's written consent. Do not use photographs of identifiable children from image libraries as if they were Khanya families.
- Write specific alt text in the CMS. Describe what can be seen and why it matters, not "image of children".
- The `Photo` and `PhotoFrame` components fall back to a branded placeholder if a file is missing, so the site remains presentable while photographs are being collected.

## Replacing an image through the CMS

1. Sign in at `/admin`.
2. Open **Media** and upload the new file. Give it descriptive alt text.
3. Open the page, programme, branch, post, event or album that uses the image and choose the new media item.
4. Save, then open the public page in a new tab to confirm the crop.

Uploaded files are stored by the API in `api/uploads/` and served through the web app at `/uploads/...`. The files in this folder are for seed content only and are served at `/images/...`.
